### 1. Migration of External Traffic Routing to NGINX Ingress Controller

#### Objective

Centralize external traffic management and reduce dependency on multiple Azure LoadBalancer services.

#### Work Completed

* Deployed and configured the NGINX Ingress Controller.
* Migrated PostgreSQL, GetStream, Durable Streams, and application services from direct LoadBalancer exposure to ingress-based routing.
* Configured centralized host and path-based routing rules.
* Implemented cross-namespace routing to expose services running in the monitoring namespace through the same ingress layer.
* Validated connectivity between Azure Load Balancer, NGINX Ingress Controller, and backend services.

#### Outcome

* Consolidated external access through a single ingress entry point.
* Reduced infrastructure complexity and the number of publicly exposed LoadBalancer services.
* Simplified routing management and future TLS/certificate administration.
* Enabled seamless access to monitoring services without additional LoadBalancers.
* Established a scalable and maintainable networking architecture for future deployments.

## Issue 2: HTTPS Certificate Trust Warning (Open)

#### Problem Statement

The application is currently secured using a self-signed TLS certificate. As the certificate is not issued by a trusted Certificate Authority (CA), browsers display security warnings and classify the connection as untrusted.

#### Impact

* Browser security warnings during application access.
* Reduced user trust in the HTTPS connection.
* Potential issues for external integrations that require trusted certificates.

#### Findings

* The current certificate was generated internally and is self-signed.
* Certificate validation fails because the issuing authority is not recognized by standard browser trust stores.

#### Planned Resolution

* Deploy Cert Manager within the Kubernetes cluster.
* Configure Let's Encrypt as the certificate issuer.
* Automate certificate issuance and renewal.
* Update ingress resources to utilize CA-signed certificates.
