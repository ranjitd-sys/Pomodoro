**Shared Worker**

Working on web worker and shared worker

```
const connectedPorts = [];

self.onconnect = (event) => {
  const port = event.ports[0];
  connectedPorts.push(port);

  port.onmessage = (e) => {
    console.log("Shared Worker received:", e.data);

    
    connectedPorts.forEach((p) => {
      p.postMessage(`Broadcast: ${e.data}`);
    });
  };

  port.start(); 
};
```
