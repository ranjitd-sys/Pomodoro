<div class="bug-card">
  <span class="badge p0">P0</span><span class="badge" style="background:#F1EFE8;color:#444441">Bug #5</span>
  <h3>pdfParser invoked with no input + no guard</h3>
  <p>In <span class="loc">maruti.machine.ts</span> <code>pdfParser</code> state, the <code>invoke</code> has no <code>input</code> field. The <code>FIRSTCRY_COMPLETED</code> event carries <code>filePaths</code>, but XState never passes it to the actor — so <span class="loc">pdfParserActor_</span> always gets <code>cdnLink: undefined</code>. Also no guard prevents firing when <code>filePaths</code> is empty.</p>
  <div class="fix"><strong>Fix:</strong> Add <code>input: ({ event }) =&gt; ({ cdnLink: (event as FirstcryCompleted).filePaths?.[0] })</code> to the invoke. Add a <code>guard: ({ event }) =&gt; !!(event as FirstcryCompleted).filePaths?.length</code> on the FIRSTCRY_COMPLETED transition.</div>
</div>

<div class="bug-card">
  <span class="badge p3" style="font-size:1rem">Solution: added guard rail</span><span class="badge" 

</div>
<br>

```FIRSTCRY_COMPLETED carries filePaths:

// { type: "FIRSTCRY_COMPLETED"; filePaths: string[] }

FIRSTCRY_COMPLETED: {
  target: "pdfParser",
  guard: ({ event }) =>
    !!(event as { type: string; filePaths?: string[] }).filePaths?.length,
  actions: () => console.log("Firstcry completed, launching PDF parser"),
},


pdfParser: {
  invoke: {
    src: "pdfParserActor_",
    input: ({ event }) => ({
      cdnLink: (event as { type: string; filePaths: string[] }).filePaths[0],
    }),
    onDone: { target: "idle" },
    onError: { target: "idle" },
  },
},

```
